# 💪 Flex Gem: Gym & Fitness Website

A multi-page gym website with a full training library: workout pages for every muscle group, with exercise videos, sample weekly schedules, membership plans and a sign-up form.

## Features

- **Home page** with a hero section and a "Why Flex Gem" section
- **Training library** covering chest, back, legs, arms, shoulders, biceps, triceps, abs and cardio
  - Each muscle page lists exercises with **demo videos** and a **sample workout schedule**
- **Overview page** with a daily task schedule and notes on bulking, cutting and general fitness
- **Membership plans**: Monthly, 3 Months and Yearly
- **Registration form** written in JavaScript:
  - Calculates the membership start and expiry dates from the chosen plan
  - Saves members to `localStorage`
- **Responsive layout** using CSS media queries

## Run locally

No build step needed. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Shokri2/Flex-Gem-Sdk.git
```
